# Wazuh OVA Deployment Guide

## 1. Download the OVA

Download the official Wazuh OVA:
https://wazuh.com/downloads/

OVA includes:
- Wazuh Manager
- Wazuh Indexer
- Wazuh Dashboard

## 2. Import OVA

In VirtualBox / VMware:
- File → Import Appliance
- Select the OVA
- Assign:
  - CPU: 4 vCPU
  - RAM: 8 GB
  - Disk: 50–100 GB

## 3. Initial Configuration

After boot:
- Login: `admin`
- Default password: `admin`
